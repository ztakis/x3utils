# 2. Windows Quick Start

## Start

1. Download and unzip x3utils.
2. Open the `x3utils_win` folder.
3. Double-click `launcher.bat`.
4. Choose the correct connection mode.
5. Run option `2` to make a full 128 KB backup.

`START with Launcher.txt` is only a reminder. The real app is `launcher.bat`.

## Flashing A File

1. Use option `4` to load a `.bin` file.
2. Use option `3` to flash the loaded file.
3. Keep the ST-LINK connection stable until verify completes.

The validator only accepts `.bin` files that are exactly `131072` bytes.

## First Thing To Try

Before flashing anything, run:

```text
[2] Run Full Memory Dump (128 KB)
```

This proves the wiring and adapter can read the chip, and it gives you a backup.
