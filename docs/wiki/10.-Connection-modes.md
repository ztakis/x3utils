# Connection Modes

x3utils has three persistent connection modes.

The selected mode is saved by the launcher and stays active until changed.

## A - Default / Blinker Buttons

Use this when SWD is available normally, or when the scooter can enter a service mode by holding the turn indicator buttons during power-up.

More: [Default SWD and blinker buttons](11.-Default-SWD-and-blinker-buttons)

## B - C45 / Clone ST-LINK

Use this with common clone ST-LINK adapters.

Many clones do not have a working reset pin, so x3utils guides the user to touch C45 to `GND` during connection.

More: [Clone ST-LINK C45 mode](12.-Clone-ST-LINK-C45-mode)

## C - C45 / Genuine ST-LINK

Use this with a genuine ST-LINK adapter or working Nucleo ST-LINK reset output connected to the chip reset line.

More: [Genuine ST-LINK reset mode](13.-Genuine-ST-LINK-reset-mode)

## T - Countdown Timer

Mode `B` also exposes a countdown timer. Increase it if you need more time during the manual C45-to-`GND` step.
