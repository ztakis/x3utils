<!-- # Default SWD And Blinker Buttons -->

Use launcher mode:

```text
A - Default / Blinker buttons
```

## When This Works

This mode works when the chip SWD interface is available.

SWD may be available because:

- the current firmware does not disable it;
- the VCU firmware enters a service mode when powered while holding the turn indicator buttons.

## Basic Flow

1. Connect the normal SWD pins for your model.
2. Hold the turn indicator buttons if your model guide says to.
3. Power the VCU.
4. Run a full dump first.

## Notes

This mode avoids manual C45 reset timing, but it only works when SWD is actually available.

If mode `A` does not connect, try the clone C45 or genuine reset mode depending on your adapter.
