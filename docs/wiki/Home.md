# x3utils Wiki

This wiki is the hardware and procedure manual for x3utils.

Use the main README and platform READMEs to start the tool. Use this wiki to understand ST-LINK, connection modes, scooter-specific wiring, backups, troubleshooting, and advanced notes.

## Start Here

1. Learn what ST-LINK is.
2. Identify your adapter and pins.
3. Choose the correct connection mode.
4. Open the guide for your scooter / VCU.
5. Run a full 128 KB dump before flashing anything.
