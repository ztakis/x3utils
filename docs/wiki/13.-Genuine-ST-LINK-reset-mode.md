<!-- # Genuine ST-LINK Reset Mode -->

Use launcher mode:

```text
C - C45 / Genuine ST-Link
```

This mode is for a genuine ST-LINK adapter or a Nucleo ST-LINK section with a working reset output.

## What Is Different

The adapter reset pin is connected continuously to the chip reset line.

On supported VCUs, that reset line is usually available at C45, but exact connection points belong in the model guide.

## Why Use It

The adapter controls reset directly, so the user does not need to manually touch C45 to `GND` during a countdown.

## First Test

Run a full dump first.

If dump and verify-style reads are stable, flashing is much less likely to fail because of wiring.

## Notes

Do not use this mode with a clone adapter unless you have confirmed the reset pin actually works.

Advanced notes for Nucleo and genuine ST-LINK setups: [Using a genuine ST-Link](35.-Using-a-genuine-ST‐Link)
